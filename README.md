# 3CAT Handcrafted Beverage — Website

A dark, cinematic single-page website for **3CAT Handcrafted Beverage** (Koreatown, Los Angeles),
built on the "Vigne" editorial design language: deep burgundy background, aged-champagne accents,
warm terracotta highlights, and Cormorant Garamond italic display type.

## Tech Stack

- [React](https://react.dev) + [Vite](https://vite.dev) + [TypeScript](https://typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com) v3 (HSL design tokens, shadcn/ui conventions)
- [Motion](https://motion.dev) (`motion/react`) for animation
- shadcn/ui-style components (`cn()` + `class-variance-authority`)
- [lucide-react](https://lucide.dev) icons

## Sections

1. **Navbar** — fixed, blurred burgundy glass, ghost "Order Online" CTA, mobile drawer
2. **Hero** — full-viewport atelier photography, dual-zone gradient overlay, overflow "3CAT"
   brand text, staggered chip strip
3. **The Menu by Category** — hover-lifting region rows (Signature, Smoothies & Frost, Mousse &
   Tea, Fresh Fruit & Tea)
4. **Made from Scratch** — 50/50 photo/content split on handcrafted toppings & ingredients
5. **House Favorites** — three featured cups (Mochi Mango, Avomango Sweet Dew, Mochi Matcha)
6. **Catering & Events** — centered statement section
7. **Testimonial** — champagne left-rule quote
8. **Order CTA** — hours + primary order button
9. **Footer** — address, hours, contact, socials (Instagram / TikTok / LinkedIn)

## Getting Started

```bash
npm install
npm run dev      # start dev server
npm run build    # type-check + production build
npm run preview  # preview the production build
```
